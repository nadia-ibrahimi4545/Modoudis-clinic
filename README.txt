ساختار پروژه

index.html      ← صفحهٔ اصلی (فقط ساختار و متن)
css/style.css   ← همهٔ استایل‌ها و حالت‌های ریسپانسیو
js/main.js      ← منو، ماشین‌حساب BMI، انتخاب پکیج و ارسال فرم
images/         ← تصاویر سایت

تنظیمات مهم (js/main.js، بالای فایل)

WHATSAPP_NUMBER : شماره واتساپ کلینیک (با کد کشور، بدون +)
FORM_EMAIL      : ایمیل دریافت پیام فرم
